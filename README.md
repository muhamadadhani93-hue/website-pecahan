# 🧭 Petualangan Detektif Pecahan - Media Pembelajaran Interaktif Matematika Kelas 5 SD

Media pembelajaran interaktif berbasis web (HTML5, Tailwind CSS, Vanilla JS) yang dirancang khusus untuk peserta didik **Kelas 5 Sekolah Dasar (Fase C)** pada mata pelajaran Matematika, khususnya materi **Pemecahan Masalah Soal Cerita Pecahan**.

---

## 🌟 Karakteristik Media
- **Tema & Desain**: Ceria, ramah anak, petualangan detektif (*cheerful cartoon style*).
- **Palet Warna**: Kuning hangat (*Warm Sun Yellow*), Biru Langit (*Sky Blue*), Hijau Mint (*Fresh Emerald*), dan Ungu Ceria.
- **Bahasa**: Komunikatif, bersahabat, terstruktur, dan mudah dipahami anak usia 10–11 tahun.
- **Teknologi**: Mandiri (*standalone*), tanpa ketergantungan server lokal, audio bawaan via Web Audio API (bebas masalah file audio eksternal), serta animasi konfeti canvas ringan.

---

## 🎯 8 Tujuan Pembelajaran yang Terintegrasi
1. **Identifikasi Diketahui**: Siswa dapat mengenali angka kuantitatif dan konteks benda dalam cerita.
2. **Menentukan Ditanyakan**: Siswa dapat menemukan inti pertanyaan dan satuan yang diminta.
3. **Menentukan Strategi/Operasi Hitung**: Siswa mampu mengidentifikasi kata kunci (misal: *sisa, digabung, membeli lagi*) untuk menentukan operasi penjumlahan (+) atau pengurangan (-).
4. **Melakukan Perhitungan**: Siswa terbiasa menyamakan penyebut pecahan (KPK) sebelum menghitung pembilang.
5. **Menyelesaikan Masalah Sistematis**: Penerapan 4 Langkah Polya (Diketahui, Ditanyakan, Model Matematika, Kesimpulan).
6. **Menuliskan Kesimpulan**: Merumuskan kalimat "Jadi, ..." lengkap dengan nama pemilik dan satuan.
7. **Menjelaskan ke Teman**: Fitur *Misi Diskusi Sebaya* dengan panduan berbicara 3 langkah.
8. **Merefleksikan Diri**: Jurnal refleksi emotif (emoji), inventarisasi kesulitan, dan strategi belajar terbaik.

---

## 📑 Struktur Isi Media
1. **Slide Pembuka & Identitas**:
   - Judul ceria dan sambutan pembuka.
   - Input Nama Siswa & Pemilihan Avatar Detektif (Kucing, Rubah, Panda, Burung Hantu).
   - Tombol Cepat Akses Game Pecahan.
2. **Misi Belajar (Tujuan Pembelajaran)**:
   - 8 Kartu Misi interaktif dengan penghitung capaian.
3. **Materi Inti Singkat (4 Jurus Polya)**:
   - Tab interaktif Jurus 1 hingga Jurus 4.
   - Kamus Kata Kunci Ajaib Soal Cerita (+ dan -).
4. **Laboratorium Kasus Nyata (Aktivitas Interaktif)**:
   - Studi Kasus 1: Pesta Kue Ulang Tahun (Penjumlahan dengan simulasi visual lingkaran pizza SVG).
   - Studi Kasus 2: Jus Jeruk Segar (Pengurangan dengan simulasi visual gelas ukur SVG).
   - Kartu Tantangan Berbagi & Menjelaskan kepada Teman Sebangku.
5. **Kuis & Evaluasi Interaktif (Multi-Tipe)**:
   - **Pilihan Ganda (PG)**: Menentukan model matematika dan kesimpulan kontekstual.
   - **Benar / Salah**: Mengevaluasi pernyataan identifikasi dan cara menyamakan penyebut.
   - **Mencocokkan Kartu**: Menjodohkan potongan kalimat soal dengan 4 status Polya.
   - *Umpan Balik*:
     - **Benar**: Ucapan apresiasi gembira, animasi konfeti, suara *pling* melodi, dan poin bintang.
     - **Kurang Tepat**: Penjelasan mendalam ramah anak, motivasi hangat, dan tombol *Coba Jawab Ulang*.
6. **Fitur Game Interaktif ("Toko Roti Detektif: Racik Pecahan!")**:
   - Dapat diakses kapan saja melalui tombol **🎮 Main Game!** di bagian atas dan beranda.
   - Pesanan soal cerita cepat dari pelanggan hewan lucu (Kelinci Lulu, Beruang Kiko, Rubah Rino, dll.).
   - Dilengkapi sistem 3 Nyawa Hati (❤️ ❤️ ❤️), skor bintang, dan efek suara.
7. **Umpan Balik, Refleksi & Sertifikat**:
   - Pilihan emoji perasaan belajar.
   - Checklist bagian paling membutuhkan ketelitian.
   - Kolom penulisan strategi terbaik siswa.
   - **Sertifikat Kelulusan Detektif Pecahan** resmi yang mencantumkan nama siswa, tanggal otomatis, gelar detektif, dan tombol **Cetak / Simpan PDF**.

---

## 🚀 Cara Menjalankan Media Pembelajaran
1. Buka folder `Media Micro`.
2. Klik dua kali (*double click*) file **`index.html`**.
3. Aplikasi akan langsung terbuka di browser Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, dll.).
4. Media ini juga sangat responsif untuk ditampilkan melalui:
   - Proyektor di depan kelas.
   - Komputer lab sekolah / Chromebook.
   - Tablet atau smartphone peserta didik.

---

## 💡 Panduan untuk Guru di Kelas
1. **Kegiatan Awal (10 Menit)**:
   - Ajak siswa membuka slide pembuka, menuliskan nama mereka, dan memilih avatar favorit.
   - Buka slide **Misi Belajar** untuk menyepakati target capaian bersama.
2. **Kegiatan Inti (40 Menit)**:
   - Eksplorasi **4 Jurus Detektif** dan **Kamus Kata Kunci**.
   - Arahkan siswa ke **Lab Kasus** untuk mengamati representasi visual potongan kue dan gelas jus.
   - Berikan waktu 5 menit bagi siswa untuk menyelesaikan *Misi 7: Tantangan Berbicara dengan Teman Sebangku*.
   - Minta siswa mengerjakan **Kuis Detektif** mandiri untuk menguji pemahaman.
3. **Kegiatan Tambahan / Gamifikasi (15 Menit)**:
   - Buka tombol **🎮 Main Game!** untuk sesi tantangan cepat Toko Roti Pecahan.
4. **Kegiatan Penutup & Refleksi (15 Menit)**:
   - Siswa mengisi jurnal refleksi diri dan mencetak / menyimpan Sertifikat Kelulusan mereka sebagai bentuk apresiasi prestasi belajar.
