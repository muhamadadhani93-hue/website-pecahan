# 🧭 Petualangan Detektif Pecahan - Media Pembelajaran Interaktif Matematika Kelas 5 SD

Media pembelajaran interaktif berbasis web (HTML5, Tailwind CSS, Vanilla JS) yang dirancang khusus untuk peserta didik **Kelas 5 Sekolah Dasar (Fase C)** pada mata pelajaran Matematika, khususnya materi **Pemecahan Masalah Soal Cerita Pecahan**.

---

## 🌟 Karakteristik Media
- **Tema & Tipografi**: Petualangan detektif ceria (*Fredoka*, *Nunito*, dan *Cinzel*).
- **Tone Warna Judul**: **2 Tone Warna Bersih: Hitam & Orange** (tanpa efek pelangi/rainbow agar lebih fokus, profesional, dan nyaman dibaca anak).
- **Label Fitur Bersih**: Penamaan fitur langsung tanpa penomoran kaku (misal: *Beranda*, *Panduan*, *Tujuan*, dll.).
- **Responsivitas**: Optimal untuk tampilan **Desktop** (Laptop/Komputer/Smartboard) dan **Android** (Smartphone & Tablet).
- **Sertifikat Full Landscape**: Tampilan sertifikat resmi bergaya ijazah kehormatan yang otomatis terformat dalam mode **Landscape (A4)** saat dicetak / disimpan PDF.
- **Teknologi**: Mandiri (*standalone*), tanpa ketergantungan server lokal, audio Web Audio API (tanpa file audio eksternal), serta animasi konfeti canvas ringan.

## 📑 Rincian Setiap Langkah Media

- **🏠 BERANDA**:
  - Sambutan pembuka detektif cilik kelas 5 SD.
  - Input nama siswa dan pemilihan avatar (🐱 Kucing, 🦊 Rubah, 🐼 Panda, 🦉 Burung Hantu).
  - Pintasan alur dan ringkasan fitur detektif.
- **📖 PANDUAN PENGGUNAAN**:
  - 6 Langkah mudah bagi siswa dalam menjelajahi aplikasi.
  - Panduan alokasi waktu dan tips pengajaran untuk Bapak/Ibu Guru di kelas.
- **🎯 TUJUAN PEMBELAJARAN**:
  - 8 Sasaran capaian pembelajaran Fase C (Identifikasi Diketahui, Ditanyakan, Operasi Hitung, KPK, 4 Polya, Kesimpulan, Kolaborasi, dan Refleksi).
- **📚 MATERI**:
  - Konsep dasar pecahan dalam kehidupan nyata (pembilang & penyebut).
  - Kunci emas menyamakan penyebut pecahan yang berbeda (KPK).
  - Kamus Kata Kunci Ajaib soal cerita (+ dan -).
- **🔎 4 JURUS DETEKTIF**:
  - 4 Langkah Polya sistematis: Diketahui, Ditanyakan, Model Matematika & Hitung, serta Kesimpulan Kontekstual.
  - Tab interaktif contoh soal dan tips detektif.
- **🧪 LAB KASUS / PBL**:
  - Studi Kasus 1: Pesta Kue Ulang Tahun Ibu (Penjumlahan dengan simulasi kue pizza SVG).
  - Studi Kasus 2: Berbagi Jus Jeruk Segar (Pengurangan dengan simulasi teko jus SVG).
- **🎮 GAME**:
  - Game interaktif *"Toko Roti Detektif: Racik Pecahan!"*.
  - 5 Pesanan cerita pelanggan hewan, sistem 3 nyawa hati (❤️ ❤️ ❤️), poin bintang, dan efek suara.
  - Kolom tautan game online luar (Wordwall / Quizizz).
- **👥 TANTANGAN BERSAMA**:
  - Misi diskusi sebaya: *"Mengapa 1/2 + 1/4 tidak boleh langsung jadi 2/6?"*.
  - Skenario kasus bersama (Tali Pramuka Edo & Udin).
  - 3 Aturan emas berdiskusi dan tombol konfirmasi penyelesaian (+20 Poin ⭐).
- **🏆 KUIS**:
  - 5 Soal lisensi detektif (Pilihan Ganda, Benar/Salah, dan Menjodohkan Kartu Polya).
  - Bobot: 20 Poin per soal (Total 100 Poin maksimal).
  - Sistem 3 Nyawa (❤️❤️❤️): jika salah 3 kali, nyawa habis, soal berikutnya tidak ditampilkan, dan skor langsung dihitung dari jawaban yang benar.
  - Ulasan & Penjelasan Refleksi Soal: setiap soal yang dijawab salah disertai penjelasan konsep dan analisis jurus Polya secara mendalam.
- **💭 REFLEKSI**:
  - Jurnal refleksi emotif (pilihan emoji perasaan belajar).
  - Pilihan bagian yang paling membutuhkan ketelitian.
  - Kolom penulisan strategi terbaik siswa.
- **🏅 HASIL / MISI SELESAI**:
  - Rekapitulasi perolehan bintang ⭐, skor kuis, dan gelar detektif (*Master Polya*).
  - **Sertifikat Kelulusan Resmi Full Landscape** yang dapat dicetak atau disimpan langsung sebagai PDF (`window.print()`).

## 🚀 Cara Menjalankan Media Pembelajaran
1. Buka folder `Media Micro`.
2. Klik dua kali (*double click*) file **`index.html`**.
3. Aplikasi akan langsung berjalan di peramban web (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, dll.) pada laptop, PC, tablet, maupun smartphone Android.
